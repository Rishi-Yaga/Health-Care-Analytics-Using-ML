# ❤️ Heart Failure Prediction using Machine Learning

## 📌 Overview
This project builds a Machine Learning model to predict the risk of heart failure using clinical and demographic patient data. The objective is to support early intervention, reduce hospital readmissions, and enable data-driven healthcare decisions.

---

## 🚀 Project Highlights

- Hospitals struggle to identify high-risk heart failure patients early, increasing readmission rates.  
- Build a predictive model to classify patients based on heart failure risk.  
- Performed EDA trained Logistic Regression, Random Forest, and XGBoost models with cross-validation.  
- Achieved **85%+ accuracy** and identified key predictors.
